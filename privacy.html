Privacy Policy

Last updated: September 22, 2026

This policy covers the personal command-line and desktop automation tools operated by Andrew Bochek ("the tools"). These tools run on the owner's own computers and access the owner's own Google account data. They are not distributed to third parties and have no external users.

1. What the tools access

With explicit consent granted through Google's OAuth 2.0 flow, the tools may access the following data belonging to the authorising Google account:

  • Google Sheets — reading and updating spreadsheets the account can open.
  • Google Drive — listing and downloading files already accessible to the account.
  • Gmail — reading, searching and sending mail on the account's behalf.
  • Google Calendar — listing and creating events.
  • Google Docs — reading and appending document content.
  • Contacts (read-only) — reading the account's contact list.

2. How the data is used

Accessed data is used solely to perform the tasks the owner explicitly requests — for example, copying values between spreadsheets, producing a document, or filing a calendar entry. No data is used for advertising, profiling, or any purpose beyond carrying out those requested operations.

3. Storage and retention

An OAuth refresh token is stored locally on the owner's machine so the tools can run without re-authorising on every use. Data retrieved from Google is processed in memory or written to local files on the owner's own devices only. No Google user data is uploaded to third-party servers, sold, rented, or shared.

4. Third parties

The tools do not transmit Google user data to advertisers, data brokers, or any other third party. The tools communicate directly with Google APIs. Where a task involves an external AI model provider, only the specific text the owner asks to be processed is sent, and never credentials.

5. Security

Credentials are stored on the owner's local machine and are never committed to public repositories. Access can be revoked at any time.

6. Revoking access

The authorising account holder can revoke the tools' access at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored token.

7. Children

These tools are not directed at children and are not offered as a public service.
